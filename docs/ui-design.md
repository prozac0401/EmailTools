# UI 디자인

EmailTools의 로컬 브라우저 화면에 차분한 회색 바탕, 흰 작업 영역, 파란색 강조를 적용했습니다.
외부 폰트, CDN, 아이콘 라이브러리 없이 시스템 글꼴과 내장 SVG만 사용합니다.

[초기 화면](ui-overview.png) · [결과 미리보기](table-preview.png) · [좁은 창](ui-mobile.png)

## 참고한 상용 앱

- [Linear 디자인 리프레시](https://linear.app/now/behind-the-latest-design-refresh):
  본문 중심의 대비, 간결한 내비게이션, 작은 아이콘과 부드러운 경계선.
- [Linear UI refresh](https://linear.app/changelog/2026-03-12-ui-refresh):
  일관된 헤더와 보기 제어.
- [Outlook 읽기 창](https://support.microsoft.com/en-us/outlook/use-and-configure-the-reading-pane-to-preview-messages-in-outlook):
  작업 영역에 맞춰 조정하는 목록과 미리보기 배치.

이 원칙을 참고해 구현했으며 해당 제품의 이미지나 코드를 사용하지 않았습니다.

## 화면과 조작

- 상단 소개 영역 없이 메일 입력부터 바로 시작합니다. 샘플 버튼은 ‘메일 불러오기’ 옆에 있습니다.
- 실행 방식은 기존 통합 앱과 동일한 `run.bat → 내장 Python → 로컬 서버 → 기본 브라우저`입니다.
  UI 변경으로 외부 서버나 새 실행 의존성을 추가하지 않았습니다.
- 메일 입력과 실행 옵션을 같은 영역에 배치하고, 선택한 옵션과 프리셋을 색상 및 체크 상태로 표시합니다.
- 넓은 창에서는 입력과 옵션을 나란히 배치하고 950px 이하에서는 세로로 배치합니다.
- 결과 영역의 열 설정은 240~420px 범위 안에서 가용 공간에 맞춰 조절됩니다.
  구분선 드래그, 좌우 방향키, Home/End를 지원합니다.
- 800px 이하에서는 열 설정과 미리보기를 세로로 배치합니다. 열 설정을 접으면 미리보기만 표시합니다.
- 데스크톱의 작업 영역 높이는 창 높이에 맞춰 460~660px 안에서 변하고, 긴 열 목록과 표는 내부에서 스크롤됩니다.
- 데이터 표의 열 제목과 행 번호는 스크롤 중 고정됩니다. 긴 셀은 클릭해서 전체 내용을 확인합니다.
- 키보드 초점 표시, 본문 건너뛰기, 스크린 리더용 상태, 움직임 감소 및 고대비 설정을 지원합니다.

## 검증

`tests/gui_smoke.cjs`는 실제 Python 서버와 Edge에서 열 편집, 미리보기와 Excel 내용 일치,
ZIP 저장, EML 업로드, 재분석, 키보드·마우스 크기 조절, 열 설정 접기와 반응형 배치를 검증합니다.
데스크톱·모바일 초기 화면 및 결과 화면 PNG도 생성합니다. 실행 방법은 README를 참고하세요.
