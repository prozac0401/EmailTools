# Windows 앱 사용 안내

1. ZIP을 모두 풀고 **run.bat**을 실행합니다.
2. 원하는 작업을 선택합니다. 기본은 메일 목록만입니다.
3. 파일·폴더를 선택하거나 샘플로 체험하기를 누릅니다.
4. 목록 만들기 / 표까지 분석하기를 누릅니다. 분석이 완료되면 결과 검토 화면이 자동으로 열립니다.
5. 표 분석에서는 필요한 후보를 추가하고 ⓘ로 통계·출처를 확인합니다.
6. 선택한 열을 끌거나 이동 버튼으로 순서를 바꿉니다. 사용자 열도 추가할 수 있습니다.
7. 저장할 표에서 전체 값과 순서를 확인합니다.
8. 저장 구성 확인에서 폴더와 산출물을 고른 뒤 결과 저장을 누릅니다.
9. 완료 후 생성된 폴더나 Excel을 엽니다.

`run.bat`은 `runtime/python/python.exe`로 실행하며 앱과 함께 콘솔 창이 열립니다.
콘솔 첫 줄의 `[Runtime]`에서 사용 중인 Python 경로를 확인할 수 있습니다.

본문·표 13px, 입력 14px로 글꼴을 줄였습니다. 오른쪽 위 글자 크게/기본으로 전환합니다.
글자 설정만 기억하고 메일·경로는 설정 저장소에 남기지 않습니다.

파일·폴더는 ‘메일 불러오기’ 영역에 끌어 놓거나 선택 버튼으로 지정합니다.
탐색기의 ‘경로로 복사’도 경로 입력란에 붙여 넣을 수 있습니다. 여러 파일의 경로는
각각 큰따옴표로 감싼 형태를 지원합니다. 없는 경로는 분석 전에 안내합니다.
파일을 지정한 다음 **목록 만들기 / 표까지 분석하기**를 눌러야 분석이 시작됩니다.
기본 ‘메일 목록만’에서는 표를 분석하지 않습니다. 본문·Word 첨부의 표가 필요하면
**목록·첨부·표 분석** 또는 **표만 취합**을 선택합니다.

검색·출처 필터는 조회만 바꾸며 전체 메일을 저장합니다.
오류·중지 시 이전 분석과 열 선택을 유지합니다.
설정 취소 · 결과로 버튼으로 이전 완료 결과로 돌아갈 수 있습니다.
새 파일·폴더를 분석하면 이전 검색·출처 조건을 초기화하여 새 결과를 표시합니다.
표가 없는 메일은 표 항목 화면에 그 이유를 안내하며, 메일 목록은 확인할 수 있습니다.

시작 오류는 %TEMP%/EmailTools-startup.log에 기록합니다.
분석·결과 표시 오류는 진행 화면의 **오류 상세 보기**에서 확인할 수 있습니다.
오류 기록은 %LOCALAPPDATA%/EmailTools/logs/desktop.log에 저장합니다.
소스 실행에서 Qt가 없다면 setup_desktop.bat으로 준비합니다.
포터블 ZIP은 런타임을 포함하여 인터넷 없이 실행할 수 있습니다.
